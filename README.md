# PCA-Based Dimensionality Reduction and Classification

## About the Project

This project uses Principal Component Analysis (PCA) to reduce the number of features in the Iris dataset and classify iris flowers using Machine Learning.

I have used Python and Flask to build a simple web dashboard where users can enter flower measurements and get a prediction.

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Flask
* HTML and CSS
* Chart.js

## Project Features

* Dimensionality reduction using PCA
* Iris flower classification
* Prediction through a web dashboard
* PCA visualization
* Model accuracy and confusion matrix

## Dataset

The project uses the Iris dataset, which contains 150 samples, 4 input features, and 3 flower classes.

## How to Run the Project

1. Clone or download this repository.

2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open `http://127.0.0.1:5000` in your browser.

## Project Objective

The main objective is to understand how PCA reduces data dimensions while retaining useful information and how machine learning can be used for classification.

## Conclusion

This project helped me understand dimensionality reduction, model training, classification, and how to connect a machine learning model to a Flask web application.
